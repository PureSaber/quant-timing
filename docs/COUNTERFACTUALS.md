# 仓位与风格的固定反事实协议

本协议解释已经观察过的历史研究，不选择赢家、不增加独立样本、不改变冻结前向方案。
固定候选族在任何候选运行前写入带真实时间和输入哈希的`protocol.json`，不提供参数搜索。
这里的执行前冻结不表示历史结果未知，也不构成盲测或独立前向登记。

|候选|唯一干预|
|---|---|
|base|原配置原样回放|
|position_neutral|rules的三个模型档位统一为1；其他模型的floor和cap统一为1|
|style_neutral|仅将style.tilt设为0.5|
|joint|同时实施上面两项干预|

没有style配置时仅运行前两项，风格和交互记为不适用，不以零效应替代。
对照的run_id增加候选后缀以避免实验索引冲突；这项身份变化不改变业务参数。
模型特征及预热条件保持不变，因而position_neutral并非从首日满仓，也不是强制最终仓位为1。
外部仓位封顶、宏观、估值、日变动、回撤限制、现金、期货、费用及全部日期保持原设置。
各路径仍由原生引擎重新计算；风格改变会影响后续回撤约束和成交，这些响应属于总干预效应。
style_neutral取消信号倾斜，但保留组权重、活动度基准和偏离上限；不把它命名为被动市场基准。

所有候选使用原时钟、相同输入和相同滚动折，分别执行账户路径和原生因果截断检查。
全区间仅作描述，每折按原决策日及下一收益日独立计分。折之间不重新执行账户，重叠折不拼接。
干预效应=干预净收益−base净收益；联合交互=joint−position_neutral−style_neutral+base。
每项效应另按原生NAV连接的资产、现金、保证金、期货和模型费用分量差对账。
联合交互是此模拟系统中的有限差分，不是现实市场因果效应，也不是外样本Alpha。

任何必需候选失败，整个候选族不生成效应结论；失败及未完成候选保留。
所有候选（包括base）都不发布position_scale.json或portfolio_overlay.yaml。
来源文件变化、配置越界、收益日期不齐、归因对账失败或产物损坏均拒绝成功。

```
python -m quant_timing counterfactual --config configs/combined.yaml --out outputs/paired
python -m quant_timing verify-counterfactual --run-dir outputs/paired
```

输出包含冻结协议、每个候选的标准研究及归因产物、完整候选结果、分折效应CSV和HTML报告。
核验从原生标准产物重算效应和交互，并检查协议、配置、输入身份、日期、发布禁用及报告内容。
哈希检测记录后的改变，不认证来源真实性；公开价格、模型冲击和借券假设不会因此变成成交证据。
